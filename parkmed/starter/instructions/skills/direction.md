# Direction (Parkmed)

This project's version of Kalka's /direction. The direction is already decided: the Parkmed
look, described in @parkmed-look.md and carried by styles.css and the variables. Do not choose
a style, palette, typeface or layout system, and do not read the style guides.

What to do instead when asked for a direction:

1. Say which kind of Parkmed page the request is (a list, a form, a record, a home) and which
   starter artboard it begins from.
2. Name the parts in reading order and the one main action.
3. Continue with /parkmed-screen.
