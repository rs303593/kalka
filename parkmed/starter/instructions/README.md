# Instructions (for you, not sent to the agent)

This document carries the Parkmed look for Kalka's agents.

- **summary.md** and **rules.md** are read at the start of every conversation.
- **skills/** adds `/parkmed-screen` (draw a new screen), `/parkmed-tidy` (fix spacing and
  positioning of an imported draft) and `/parkmed-handoff` (get a screen ready for APEX), and
  replaces Kalka's `/polish` and `/direction` with Parkmed versions, because Kalka's own use
  their own colours and type and choose a new visual direction.
- **documents/parkmed-look.md** is the full look; cite it with `@parkmed-look.md`.

The values come from `parkmed/parkmed-values.json` in the Kalka checkout. If you change a
value there, change it here and in `styles.css` too.
